MarketEcho - Setup Windows

Apri PowerShell su Windows x64 e incolla:

irm https://marketecho-ai.github.io/marketecho-setup/install.ps1 | iex

Il setup prepara Git se manca, legge l'ultimo commit su main e chiede una nuova cartella e il conto Demo.

Serve accesso al repository privato di MarketEcho. La password del conto si inserisce solo in MT5. Le installazioni esistenti restano separate; nessun vecchio database viene importato.

Avvio protetto: Trading OFF, Kill ON, Algo OFF, Demo PAUSED.
